# projeto3_ML_siteprojetos

Vamos usar dados de um site onde as pessoas postam projetos que elas gostariam, como, por exemplo: 'Eu gostaria de um site para minha banda de música, com área de contato, etc.' A pessoa também estima o tempo que levaria para fazer (horas_esperadas) e quanto pagaria por ele (preco). O campo (nao_finalizado) indica se algum desenvolvedor aceitou pegar este projeto para execução."

Utilizamos Seaborn e Matplotlib para gerar gráficos de análise.  Os gráficos são cruciais para confirmar que a acurácia do nosso modelo está significativamente acima da acurácia de base (baseline), provando que o algoritmo está aprendendo e agregando valor real à previsão.
